# Abdul Rab — Academic Portfolio

A custom static academic website designed for GitHub Pages. No Jekyll, Ruby, build step, or theme dependency is required.

## Deploy
1. Create a public GitHub repository named **abdulrab.github.io**.
2. Upload the **contents of this folder** to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/(root)**.
4. Visit https://abdulrab.github.io/ after deployment.

## Edit
- Main biography: `index.html`
- Research: `research.html`
- Teaching: `teaching.html`
- Books and free-download listings: `books.html`; add approved PDFs under `assets/books/`
- Official course outlines: add approved files to `assets/course-outlines/` and link the relevant course page
- Verified course list: `assets/js/course-data.js`
- CV PDF: `assets/cv/Abdul_Rab_CV.pdf`
- Colors/layout: `assets/css/site.css`

## Optional upgrades
Add a Google Scholar and ORCID link when available, and add research figures or code links as projects develop.

## Publishing resources
The Books page links the published Class XI Mathematics Solution Manual to its Zenodo DOI (10.5281/zenodo.23264017) and displays the original cover thumbnail under `assets/books/class-xi-cover.webp`; Class XII is still forthcoming. External Zenodo downloads should be linked by DOI until an exact file URL is verified. Course outlines are also marked as forthcoming and must not be invented.
