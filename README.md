# Abdul Rab — Academic Portfolio

A custom static academic website designed for GitHub Pages. No Jekyll, Ruby, build step, or theme dependency is required.

## Deploy
1. Create a public GitHub repository named **abdulrab.github.io**.
2. Upload the **contents of this folder** to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/(root)**.
4. Visit https://abdulrab.github.io/ after deployment.

## Edit
- Main biography: `index.html`
- Research: `research.html`
- Teaching: `teaching.html`
- CV PDF: `assets/cv/Abdul_Rab_CV.pdf`
- Colors/layout: `assets/css/site.css`

## Optional upgrades
Add a Google Scholar and ORCID link when available, and add research figures or code links as projects develop.
